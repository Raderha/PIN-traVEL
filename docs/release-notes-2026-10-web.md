# 릴리스 노트 — 웹 기능 수정

- 일자: 2026-10-18
- 대상: `https://dm0kbipnsg1gx.cloudfront.net`
- 범위: `apps/web` (인프라·Lambda는 변경 없음)

## 변경 사항

- 3일차 이후 일정이 전날 숙소에서 시작하도록 수정했습니다.
- 일차별 지도에서 3일차 이후에도 숙소 아이콘이 보이도록 수정했습니다.
- 숙소를 드래그해도 다른 일차의 숙소가 사라지지 않도록 수정했습니다.
- 클라우드에서는 「세션 생성」 시 협업을 제공하지 않는다는 안내만 표시하도록 수정했습니다.

## 변경 사항 세부

1. **일정 3일차 이후 출발**  
   숙소는 매일 장바구니 끝에 들어가지만, 경로를 펼칠 때 같은 ID는 한 번만 써서 3일차가 전날 **마지막 관광지**에서 
   이어졌다. `tripHotelId`도 로컬 저장에 없었다.  
   → 여러 날 맨 끝이 같은 핀이면 숙소로 보고 경로에 매일 다시 넣고, 장바구니와 함께 ID를 저장한다.

2. **3일차 지도 숙소 아이콘**  
   일차별 보기에서는 그날 정류장만 찍어, 전날 숙소에서 출발해도 집 아이콘이 빠졌다.  
   → 그날 첫 구간의 출발점(숙소)에도 아이콘을 그린다. 장소 추가 시 숙소는 일차 맨 끝을 유지한다.

3. **숙소 드래그 시 모든 일차 숙소 삭제**  
   드래그가 같은 ID를 **모든 일차에서 지운 뒤** 놓은 날에만 다시 넣었다.  
   → 숙소는 드래그한 그날만 옮기고, 다른 날 끝의 숙소는 남긴다.

4. **클라우드 「세션 생성」**  
   Socket.IO는 Lambda에 없다. 프로덕션에서는 API를 호출하지 않고 안내만 보여 준다. 로컬 `npm run dev`는 기존과 같다.

## 검증

로컬에서 일정 재생성·일차별 지도·숙소 드래그를 확인한 뒤, 동일 경로 및 랜덤하게 생성한 경로 3종을 CloudFront에서 다시 확인했습니다.
